Methods

VisionSim HDR Web 0.5

Image values and calibration

The application keeps source RGB and luminance in floating-point arrays. Corrected geometry, calibration, image-circle support, simulations, and display settings are distinct records. A source crop selects pixels without interpolation. Simulations resample into separate arrays; they do not resize the calibrated source.

Radiance exposure and COLORCORR records are reversed once when interpreting stored RGB. Luminance is formed from the declared primaries or an explicit input interpretation. A supported Radiance scale is 179 times normalized Y; supported EXR metadata can supply a different scale, including whiteLuminance. An imported file convention is not an independent meter validation. Photosphere-generated HDR and EXR may carry equivalent scaling in different forms.

K = measured target luminance / mean unscaled target Y
L(x,y) = K * Y(x,y)

The patch anchor accepts a positive meter value in cd/m2. Cropping and masking preserve K. Header-only HDR export changes only geometry records and retains the original pixel payload and photometric records; it does not apply a new session anchor. Prepared HDR exports the current raster and active scale convention. RGBE is quantized; numeric PFM is float32. Saved PNGs are display images.

JPEG bracket reconstruction

Response estimation uses the Debevec-Malik log-response equations independently for R, G, and B, with weighted least squares, a smoothness penalty, and an arbitrary response anchor. At least three exposures are required for fitting, or two with an imported response JSON. Exposures are decoded sequentially for reconstruction; there is no fixed count cap. Working dimensions and a memory budget limit allocations. Fixed aperture, ISO, white balance and processing are expected. Motion alignment and deghosting are not performed. Unsupported pixels remain marked invalid rather than becoming measured black pixels.

Debevec and Malik, Recovering High Dynamic Range Radiance Maps from Photographs (1997).

Projection geometry

Angles refer to scene rays, not the displayed size of a browser canvas. A correct lens projection and circle extent are required. Resizing does not change FOV; a crop changes its angular coverage and principal-point location. For a rectilinear lens with actual focal length f and active sensor width S, horizontal FOV is 2 atan(S/(2f)); the analogous equation applies vertically. Metadata-assisted estimates require user review.

For a centered circular image of radius R and edge polar angle T (half its diameter FOV), the supported normalized radial laws are:

Equidistant:    r/R = theta/T
Equisolid:     r/R = sin(theta/2)/sin(T/2)
Stereographic: r/R = tan(theta/2)/tan(T/2)
Hemispherical: r/R = sin(theta)/sin(T)

Rays are represented internally as right, down, forward. Unit vectors are used for masks and angular separation. A perspective view cannot represent a finite 180-degree image: tan(FOV/2) diverges. The optional angular export resamples pixels into an equidistant Radiance -vta file. Editing a header alone does not perform that conversion. Full circular analysis reads the confirmed source projection directly.

Reduced-detail visibility model

The core luminance filter uses cosine bands in log spatial frequency, local-contrast thresholds and same-sign spatial feathering. It retains the clinical parameterization of the supplied DeVAS-derived implementation:

S_peak = 2 * 10^P - 1                    (P = Pelli-Robson score)
F_normal = 0.914 * 10^(sqrt(log10(199))/1.28)
F_cutoff = F_normal * 10^(-logMAR)
F_peak = F_cutoff / 10^(sqrt(log10(S_peak))/1.28)
S(f) = 10^[ log10(S_peak) - k^2 * (log10(f/F_peak))^2 ]
k = 0.68 below F_peak, 1.28 at/above F_peak

The nominal cutoff is about 13.97897 cycles/degree, not a substituted 30 cycles/degree. For logMAR 1 and Pelli-Robson 1, cutoff is 1.397897 cycles/degree and peak sensitivity is 19. The feather radius is 0.35 times the band's peak wavelength, with the outer half feathered, matching the supplied code. Absolute mode uses a 0.01 cd/m2 denominator floor. Relative mode uses a mean-relative floor, so arbitrary positive scale does not create an absolute low-luminance threshold. This relative mode is an explicit adaptation.

The original method parameterizes a CSF with clinical measures and was validated using letter recognition; that does not validate every additional whole-field, display, or educational operation here. Thompson et al. (2017); DeVAS reference implementation.

Whole circular field

The full-circle mode preserves the actual circular projection and diameter FOV in its result. It uses 512, 800, or 1024 pixels square, independent of the calibrated source. Samples outside the circle are invalid support, not black scene luminance. Source samples use bilinear interpolation with a 2-by-2 subpixel average; this is finite sampling, not an ideal low-pass reconstruction.

The filter is evaluated in overlapping local tangent views rather than applying one pixels-per-degree value over a fisheye. Patch centers lie on concentric spherical rings with nominal 12-degree spacing. A 180-degree field uses 171 patches. Each patch spans 32 degrees; only its central 12-degree radius contributes, with weights (1 - (theta/12)^2)^2 normalized by their sum. Patches can use 96, 192, or 384 samples across. The local central scale is:

f_pixels = N / (2*tan(16 degrees))
pixels_per_degree = f_pixels * pi/180
filter_equivalent_HFOV = N / pixels_per_degree = 32.8586008 degrees

The equivalent width passed to the existing FFT core encodes the correct central scale; it is not the physical patch FOV. Within a retained patch, the largest local perspective scale change relative to its center is sec(12 degrees)^2 - 1 = 4.518%. This is a bound on local projection-scale variation, NOT a 4.518% error bound for the whole visibility model. Nonlinear thresholds, finite patch context, interpolation and blending introduce additional approximation. Angular reflection supplies filter support at the captured rim; it is a boundary condition, not invented output scene coverage. Patch calculations then use the existing reflected FFT padding.

Whole-field output is an exploratory local tangent approximation, not an exact spherical DeVAS implementation or a model of peripheral retinal acuity. Acuity and contrast sensitivity are applied uniformly across viewing directions. Sampling, camera optics and source processing constrain interpretation. This release does not add adaptation, disability glare or a geometry-based hazard score.

Sampling

For a radial image law r(theta), radial and tangential pixels per radian are dr/dtheta and r/sin(theta). The application reports the conservative minimum over the field, divided by two after converting to pixels/degree, and also checks patch sampling. An 800-pixel, 180-degree equidistant circle has radial Nyquist 2.2222 cycles/degree; an equisolid circle of the same size has a minimum radial Nyquist 1.7453 cycles/degree at the rim. An orthographic/hemispherical mapping approaches zero radial sampling at a 90-degree edge. Increasing display size or source upsampling cannot recover missing detail.

Local perspective detail

The original 5-60 degree local view remains available. It retains the previous global-width/HFOV approximation within that view, not spatially varying retinal sampling. It is useful for smaller angular regions. A rectangle here is a separate reprojected result and never a source crop.

Educational color effects

Angular field restrictions use separation between normalized rays. The full-circle mode uses each fisheye pixel's ray, including off-center fixation. Fixation outside valid captured support is rejected. Scattered effects have a recorded random seed. Whole-field blur is evaluated in overlapping tangent views with sigma specified in local degrees; it is not an acuity conversion. Haze and yellowing are illustrative controls. Color-vision matrices use the attributed Machado tables. These operations copy their inputs; measurements and the source false-color map do not change.

Viewing-field references

Viewing masks are separate from low-vision filtering and the source image-circle mask. A 40-degree horizontal band selects elevation from -20 to +20 degrees, spanning the captured forward field. A 60-degree cone means a 30-degree angular radius. Custom upper/lower elevation limits are explicit user choices. Gaze yaw, pitch and roll are relative to the source optical axis and operate on ray vectors before membership tests; world gravity is not inferred from a photograph. Only directions present in the source can be shown.

Guth total-field and binocular-overlap references use an independently tabulated angular envelope at 1-degree meridian intervals with linear interpolation, corresponding to the documented Guth cut-view references. Meridian zero is upward, 90 degrees is horizontal, and 180 degrees is downward. The binocular envelope is intersected with the total envelope to avoid small inconsistencies from independently fitted outlines. The result is clipped to the captured forward hemisphere. These are reference envelopes, not individual perimetry, and are distinct from Guth's glare position index.

Van Den Wymelenberg and Inanici (2015), Fig. 2 shows the 40-degree band, binocular, human-field and central-cone masks. The documented Guth total/both-eyes cut-view definitions and angular boundary reference equations were used to check the reference-table geometry.

Mask-region statistics

The overlay reports both an equal-pixel mean and a solid-angle-weighted mean. For a radial projection, dOmega/dA = sin(theta)/(r * dr/dtheta); its central limit is used at the axis. Equisolid weights are constant. Pixel-center Jacobian quadrature is approximate, especially near the singular rim of a 180-degree hemispherical mapping. Statistics are evaluated on the separate resampled view; they do not replace native-pixel calibration or target measurements. A forward 40-degree band has analytic solid angle 2*pi*sin(20 degrees), approximately 2.148976 sr.

False color

The map uses luminance after the active scale multiplier, not preview exposure. Adjustable endpoints can be linear or logarithmic (positive minimum for logarithmic scaling). The numerical legend records units. Under/over-range colors indicate display classification only. False-color and overlay PNGs include their displayed legend; they are not quantitative HDR exports.

Input formats

Radiance RGBE/XYZE, supported lossless single-part scanline EXR, common browser-decodable photos, and aligned JPEG exposure brackets are supported. HDR/EXR readers retain their existing size safeguards. Phone JPEG gain-map support and metadata-aware EXIF orientation are unchanged. HEIC/HEIF needs its optional codec; unsupported HDR variants stop or require an explicit SDR route. Gain-map reconstruction is not absolute scene calibration.

Reset behavior

Visibility reset clears its numerical result and resets acuity/contrast controls. Educational reset clears its color preview and effect settings. Reset both additionally restores shared analysis-area defaults. Viewing-overlay reset clears only the overlay and its settings. None of these changes source arrays, source crop/history, image-circle mask, header geometry, calibration multiplier, or saved source ROIs. The separate Cancel & clear session command still explicitly clears the image session.
