Explicit conversion to angular fisheye HDR

This resamples pixels into an equidistant (-vta) circle. It is different from editing a header and does not replace the original measurement image. Equisolid has no equivalent standard Radiance VIEW in the supported format; it is never silently relabeled as -vth. Unsupported interior samples block export.

Save JSON and the validity mask with numeric exports. Prepared HDR contains the current raster and confirmed geometry; RGBE encoding is quantized and negative channels are rejected. Header-only export preserves the original HDR pixel payload and photometric records; it does not apply a new patch calibration and is unavailable after cropping.
