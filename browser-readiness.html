03 / Memory planning
Image dimensions matter more than compressed file size. These calculations allocate no image memory.
A plane is one single-channel full-resolution array. The subtotal includes one float32 RGB image, the selected scratch planes, and all bracket inputs as RGBA8. It excludes decoder workspaces, FFT padding, GPU copies, output buffers, and browser overhead. The real pipeline may use a different representation.
No browser probe here measures free RAM or establishes a safe maximum file size. A successful small allocation does not guarantee a large analysis will complete. Approximate deviceMemory, where exposed, is not free memory.


Reading the results
WebAssembly + workers: the proposed baseline for numerical processing without blocking the interface.
WebGL2 float round-trip: tests storage and readback of values below and above 1.0. It does not test HDR monitor output or a visibility shader.
WebGPU: adapter detection and reported limits only. No production compute kernel is benchmarked.
Cross-origin isolation: needed for shared-memory browser threading, not for ordinary single-worker processing. A local file cannot establish the intended server's HTTP header configuration.
Final qualification: numerical reference comparisons, representative files, browser-specific stress tests, cancellation, and recovery still need to pass.
