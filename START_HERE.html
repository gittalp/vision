The scientific source remains separate from annotations and simulations. The desktop Blackmagic application is not modified.

Measure and save a region

Complete cropping first. In Measure regions above the source image, select Rectangle, Circle or Polygon and draw. The luminance appears in that toolbar. Enter a name, choose a color, and select Save named region, Save as A or Save as B.

The panel below the image lists all saved regions and their metrics. Use its A/B selectors to compare existing records. There is only one drawing workflow. Clearing a draft does not erase saved records. Saved colors and tints do not alter measured pixels.

Target and surrounding background

Save the target as A, then draw a larger containing boundary and save B. With subtraction enabled, B's reported luminance excludes A's pixels. The panel shows A/B, brighter/darker ratio, Weber contrast and two-region Michelson contrast. Regions must have matching measurement scopes.

Selections made from viewing overlays

Select / measure on source image returns to the same toolbar. Check Restrict new measurements to applied viewing field when appropriate. The saved row records that restriction. Measure entire viewing field reads native pixels, not the shaded preview.

180-degree FOV and an optical-center error

FOV describes angular extent; shift/lift describe the optical center in the raster. Correct FOV can coexist with stale center offsets. Leave Align optical center to applied image circle checked and apply geometry, or use the circle helper for a complete geometry draft. No measurement polygon controls the image-circle definition.

Set Contrast retained and Saturation retained to 1 to isolate mask shading. Opacity acts before the shared tone map, so a 50% setting is not necessarily half screen brightness. Run the simulation again after changing controls.

Retain your results

Use Regions CSV and Analysis JSON before changing source or closing the tab. New crop/mask geometry clears old source-coordinate regions. Calibration changes now recompute saved metrics; simulation resets retain saved regions.
