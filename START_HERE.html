VisionSim HDR Web 0.5

Continue with a prepared fisheye

Open the image, retain its file scale or existing target calibration, prepare the image circle, and confirm its actual projection and angular extent. Pixel/region luminance can be checked before geometry review.

See the whole circular field

In Reduced-detail visibility, leave Analysis area on Automatic, or choose Whole circular fisheye. Choose 800 x 800 for the separate output and run the simulation. The source is not resized. The full-field method blends local tangent analyses; sampling and approximation are reported below the result. Select Local perspective detail for a smaller directional view.

The bottom angular conversion is only for exporting a reprojected equidistant HDR. It is not needed for the full-circle simulations.

Start a simulation over

Use Reset visibility simulation, Reset educational simulation, or Reset both simulations. These controls keep source crop, image mask, calibration, geometry, and saved source measurements.

Add a viewing reference

In Viewing field & angular overlays, choose the 40-degree total band, central cone, Guth total field, Guth binocular reference, or custom vertical limits. Adjust orientation and presentation, then Show viewing field. Save a labeled PNG or binary PGM mask. Reset viewing overlay removes only that preview.

Keep quantitative exports separate

Prepared HDR exports the source image or bracket reconstruction. Simulation PFM exports filtered luminance; keep its support mask and Analysis JSON. PNGs show a shared tone map or an explicit false-color legend, not measured display luminance.
