VisionSim HDR Web 0.6

Open the source, crop when needed, confirm its actual projection/FOV, then inspect the file luminance scale or calibrate a measured target. The desktop Blackmagic application is separate and unchanged.

Select and compare regions

Use the toolbar above the main image. Choose Polygon, press New selection, click the target vertices, and finish with Enter or Finish polygon. Drag a vertex to refine it. Save the target as A. Draw a larger surround and save B; with automatic subtraction enabled, the application excludes A before calculating the background mean. A partial overlap is not silently subtracted.

Whole valid image is the whole-image summary. Selected region is reported separately. The crop-circle guide is hidden outside crop mode; its validity mask stays active. Show image-circle boundary temporarily reveals it.

Measure inside a viewing field

Show a band, cone or Guth-reference field. It can also appear on the main source image. Return there with Select regions on main image and enable Restrict measurements to applied viewing field. Selections now intersect that angular field. Measure entire viewing field obtains native-source statistics without drawing a region. Shaded-out pixels are excluded, not treated as black; source calibration is unchanged.

Simulate acuity and contrast sensitivity

Snellen 20/x and logMAR are synchronized. Select Color (filtered chromaticity) or Luminance only. Whole-circle and local-detail modes remain available. Color is a rendering choice, not a separate luminance calibration. All simulation resets keep the prepared source and saved measurement regions.

Low vision condition simulations

Peripheral field loss contracts an angular Guth reference using Retained angular field (%); effect strength is separate. Central field loss (AMD-like) has irregularity, elongation, eccentric offset and directional growth. These settings describe configurable visual effects, not clinical severity or a patient's measured field.

Add projection-aware angle rings

Enable Angle rings, keep the default 10-degree steps or select another interval, then choose color, opacity and width. Eccentricity labels are angular radii; Cone diameter labels are twice those radii. A 60-degree cone is a 30-degree radius. Rings follow the confirmed projection and can be centered on the optical axis or current viewing direction. Apply angular rings, then save a source or viewing-field PNG to include them.

Keep numerical outputs

Prepared HDR, numeric PFM and analysis JSON remain separate from annotated PNGs. The optional angular-HDR export is a format/projection conversion, not a prerequisite for analysis. The source image, calibration and JPEG-bracket workflow are not modified by the new controls.
